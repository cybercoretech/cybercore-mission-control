Security boundaries

Access is deliberate.

Operator access

Admin routes require an operator token. The staging dashboard is intended to sit behind Cloudflare Access; no token is bundled in static assets.

Connector access

Agent credentials are scoped, shown once at registration, and stored as hashes. The experimental connector cannot receive commands or open a listener.

Deployment status

This is an alpha observation plane, not a production control plane. Production configuration remains intentionally gated and requires separate operator readiness checks.

Not a remote shell

Mission Control does not run commands on operator machines, edit local files, or replace local task authority.
